# SOH Match Centre

A simple GAA scoreboard built with Next.js for deployment on Vercel.

## Features
- Goals and points for both teams
- Automatic total points calculation
- Match timer
- First half / half time / second half / full time states
- Mobile-friendly controls
- Display mode for a clean public scoreboard
- Match state saved in the browser

## Run locally
```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload these files to the repository.
3. Sign into Vercel and choose **Add New > Project**.
4. Import the GitHub repository.
5. Vercel should detect Next.js automatically.
6. Click **Deploy**.
